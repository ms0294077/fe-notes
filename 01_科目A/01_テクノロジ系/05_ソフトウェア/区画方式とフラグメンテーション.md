# 区画方式とフラグメンテーション

> [!summary] 一句話
> 固定区画容易產生内部フラグメンテーション；可変区画容易產生外部フラグメンテーション。

## 実記憶管理とは
- 主記憶装置（RAM）にプログラムをどのように配置・管理するか
- プログラムは基本的に RAM に読み込んでから実行する
- RAM の容量は有限なので、OS が使用領域を管理する

## プログラム内蔵方式
- English：Stored-program concept
- 中文：儲存程式概念／程式內藏方式
- 程式與資料先放進主記憶裝置，再由 CPU 讀取並執行

補助記憶装置（SSD／HDD）
↓ 読み込み
主記憶装置（RAM）
↓
CPU が実行

## マルチプログラミング
- English：Multiprogramming
- 中文：多程式處理／多道程式設計
- 複数のプログラムを RAM に置き、CPU が切り替えながら実行する
- 不一定是真的同一瞬間執行，而是快速交替執行

## プログラム読み込み方式

## 固定区画方式
- English：Fixed Partitioning
- 中文：固定分割方式
- 事先把 RAM 切成固定大小的區塊
- 每個程式只能放進其中一個固定區塊
- 管理簡單，但容易浪費空間

### 内部フラグメンテーション
- English：Internal Fragmentation
- 中文：內部碎片
- 已分配區塊內部出現未使用空間

例：

4MB 的區塊中放入 2MB 的程式
→ 剩下 2MB 無法再給其他程式使用

## 可変区画方式
- English：Variable Partitioning
- 中文：可變分割方式
- 按照程式大小分配剛好的 RAM 空間
- 比固定区画方式更節省空間
- 反覆載入與刪除程式後，容易產生零碎空間

### 外部フラグメンテーション
- English：External Fragmentation
- 中文：外部碎片
- 空閒空間總和足夠，但因為不連續，仍無法使用

例：

空閒區域：4MB、2MB、6MB
總共：12MB
但沒有連續 12MB
→ 無法載入 12MB 的程式

## メモリコンパクション
- English：Memory Compaction
- 中文：記憶體緊縮／記憶體壓縮
- 把 RAM 中的程式往一側移動
- 將分散的空閒空間合併成一大片連續區域
- 用來解決外部フラグメンテーション
- 缺點是搬動程式需要時間

整理前：

プログラム｜空き｜プログラム｜空き｜プログラム｜空き

整理後：

プログラム｜プログラム｜プログラム｜大きな空き領域

## デフラグとの違い
- デフラグ
  - English：Defragmentation
  - 中文：磁碟重組
- メモリコンパクション：整理 RAM
- デフラグ：整理 HDD 等補助記憶裝置

## FE 重點

| 概念 | 重點 |
|---|---|
| 固定区画方式 | 區塊大小固定 |
| 可変区画方式 | 按程式大小分配 |
| 内部フラグメンテーション | 區塊內部浪費 |
| 外部フラグメンテーション | 空間分散、不連續 |
| メモリコンパクション | 集中 RAM 的外部碎片 |

## 快速記憶
- 固定区画方式 → 内部碎片
- 可変区画方式 → 外部碎片
- RAM 碎片整理 → メモリコンパクション
- 磁碟碎片整理 → デフラグ
