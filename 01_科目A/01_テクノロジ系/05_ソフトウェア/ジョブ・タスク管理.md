# ジョブ・タスク管理

> [!summary] 一句話
> ジョブ是使用者提交的一整項工作；タスク是 OS 實際排程與執行的處理單位。

## ジョブ
- 英文：Job
- 中文：工作、作業
- 使用者交給電腦的一整項工作

## タスク
- 英文：Task
- 中文：任務
- OS 實際管理與執行的處理單位

## 關係
一個 Job 可以分成多個 Task。

例：列印 Excel 文件

- Task A：讀取檔案
- Task B：整理列印格式
- Task C：傳送給印表機

## ディスパッチャ
- 英文：Dispatcher
- 實際把 CPU 分配給某個 Task

## スケジューラとの違い
- スケジューラ：決定下一個執行誰
- ディスパッチャ：實際把 CPU 交給它
