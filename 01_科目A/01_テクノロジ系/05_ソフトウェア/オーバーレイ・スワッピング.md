# オーバーレイ・スワッピング

> [!summary] 一句話
> オーバーレイ由程式設計者分割程式；スワッピング由OS在主記憶與輔助記憶間換入換出。

## 21 実記憶管理②｜程式換入換出與記憶體回收

## オーバーレイ方式
- English：Overlay
- 中文：覆蓋載入法／覆疊法
- 當程式比 RAM 容量大時使用
- 把程式拆成多個セグメント
- 只把目前需要的部分載入 RAM
- 不同部分交替使用同一塊記憶體

### セグメント
- English：Segment
- 中文：區段

例：

程式：12MB
RAM：8MB

程式拆成 A、B、C 三個セグメント
→ 先載入 A
→ 不需要 A 時，用 B 覆蓋
→ 再用 C 覆蓋 B

### 缺點
- 每次切換都可能要重新從 SSD／HDD 讀取
- 執行速度可能下降
- 管理較複雜

## スワッピング
- English：Swapping
- 中文：交換／換出換入
- RAM 不夠時，把暫時不用的程式移到 SSD／HDD
- 之後需要時，再搬回 RAM

## スワップアウト
- English：Swap out
- 中文：換出
- 主記憶装置 → 補助記憶装置

## スワップイン
- English：Swap in
- 中文：換入
- 補助記憶装置 → 主記憶装置

### 流れ

RAM
↓ スワップアウト
SSD／HDD
↓ スワップイン
RAM

### 缺點
- SSD／HDD 比 RAM 慢
- 頻繁換入換出會讓系統變慢
