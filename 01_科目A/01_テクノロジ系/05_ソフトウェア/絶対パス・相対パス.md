# 絶対パス・相対パス

> [!summary] 一句話
> 絶対パス從根目錄開始；相対パス以目前目錄為基準，點表示目前、兩點表示上一層。

## ファイルパス

### ファイルパス
- English：File Path
- 中文：檔案路徑
- 表示從某個起點到目標檔案或目錄的經路

## 絶対パス
- English：Absolute Path
- 中文：絕對路徑
- 從ルートディレクトリ開始寫檔案
- 不受目前所在位置影響

例：

`/Users/orange/Documents/report.pdf`

## 相対パス
- English：Relative Path
- 中文：相對路徑
- 從カレントディレクトリ開始寫到目標檔案
- 目前所在位置改變時，路徑意義也可能改變

例：

目前在：

`/Users/orange/Documents`

目標檔案：

`/Users/orange/Documents/report.pdf`

相対パス：

`report.pdf`

## パスで使う記号

| 記號 | 意思 |
|---|---|
| `/` 或 `\` | 分隔目錄 |
| `.` | 目前目錄 |
| `..` | 上一層目錄 |
| `~` | 使用者主目錄 |

注意：
- Linux／macOS 使用 `/`
- Windows 通常使用 `\`
- 日文 Windows 環境中，`\` 有時顯示成 `¥`

## 例題

資料夾結構：

/
└─ Users
   └─ orange
      ├─ Documents
      │  └─ report.pdf
      └─ Pictures
         └─ photo.jpg

目前位置：

`/Users/orange/Documents`

### report.pdf 的絶対パス

`/Users/orange/Documents/report.pdf`

### report.pdf 的相対パス

`report.pdf`

### photo.jpg 的相対パス

`../Pictures/photo.jpg`

意思是：

上一層
↓
進入 Pictures
↓
找到 photo.jpg

## FE 常考重點

### 絶対パスと相対パス
- 絶対パス：從根目錄開始
- 相対パス：從目前目錄開始

### `.` と `..`
- `.`：目前目錄
- `..`：上一層目錄

### ルートとホーム
- ルートディレクトリ：整個系統最上層
- ホームディレクトリ：使用者個人目錄

### 親とサブ
- 親ディレクトリ：上一層
- サブディレクトリ：下一層

## 比較

| 日文         | English           | 中文     |
| ---------- | ----------------- | ------ |
| ファイル       | File              | 檔案     |
| ディレクトリ     | Directory         | 目錄／資料夾 |
| フォルダ       | Folder            | 資料夾    |
| カレントディレクトリ | Current Directory | 目前目錄   |
| 親ディレクトリ    | Parent Directory  | 父目錄    |
| サブディレクトリ   | Subdirectory      | 子目錄    |
| ルートディレクトリ  | Root Directory    | 根目錄    |
| ホームディレクトリ  | Home Directory    | 使用者主目錄 |
| ファイルパス     | File Path         | 檔案路徑   |
| 絶対パス       | Absolute Path     | 絕對路徑   |
| 相対パス       | Relative Path     | 相對路徑   |

## 快速記憶
- Directory 是資料夾，File 是裡面的資料
- Absolute Path 從根目錄開始
- Relative Path 從目前目錄開始
- `.` 是現在，`..` 是上一層
