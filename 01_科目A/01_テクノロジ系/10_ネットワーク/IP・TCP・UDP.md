# IP・TCP・UDP

> [!summary] 一句話
> IP負責尋址與路由；TCP可靠且有連線；UDP快速、無連線且不保證送達。

## IP

- **用語：** IP（Internet Protocol）
> 使用IP位址，將資料跨越不同網路送到目的地。

- 負責目的地與路線
- 資料以パケット形式傳送
- 本身不保證一定送達

## TCPとUDP

| 項目 | TCP | UDP |
|---|---|---|
| 連線確認 | 有 | 無 |
| 可靠性 | 高 | 低 |
| 遺失重傳 | 有 | 無 |
| 順序保證 | 有 | 無 |
| 速度 | 較慢 | 較快 |
| 用途 | 網頁、郵件、檔案 | 直播、通話、遊戲 |
