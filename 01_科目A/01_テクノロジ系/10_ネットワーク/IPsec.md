# IPsec

> [!summary] 一句話
> IPsec 在網路層保護 IP 封包；AH 提供認證與完整性，ESP 還可提供加密。

## IPsecとは

- **用語：** IPsec（IP Security）
> 在網路層保護 IP 通信安全的技術。

IPsec 可以提供：

- 暗号化：避免通信內容被偷看
- 認証：確認通信對象的身分
- 完全性確認：檢查資料是否遭到竄改

IPsec 常用於：

- VPN
- 公司據點之間的安全通信
- 從外部安全連回公司內部網路

## IPsecを構成する主なプロトコル

### AH

- **用語：** AH（Authentication Header）
> 提供身分認證與資料完整性檢查。

主要功能：

- 確認傳送者
- 檢查資料是否被竄改

注意：

AH 原則上不提供資料內容的加密。

### ESP

- **用語：** ESP（Encapsulating Security Payload）
> 對資料進行加密，也能提供認證與完整性檢查。

主要功能：

- 加密
- 認證
- 檢查資料是否遭到竄改

ESP 比 AH 更常使用。

### IKE

- **用語：** IKE（Internet Key Exchange）
> 在開始安全通信前，協商加密方式並交換金鑰。

白話理解：

雙方先決定：

- 使用哪種加密方式
- 使用什麼金鑰
- 如何建立安全通信

之後才利用 IPsec 傳送資料。

## IPsecの通信モード

### トランスポートモード

- **用語：** Transport Mode
> 主要保護 IP 封包中的資料部分。

通常用於：

- 主機與主機之間的通信

### トンネルモード

- **用語：** Tunnel Mode
> 將原本整個 IP 封包包起來，再加入新的 IP Header。

通常用於：

- Router 與 Router 之間
- 公司據點之間
- IPsec VPN

トンネルモード
＝把整個 IP 封包包起來
＝常用於 VPN

## FE考點

IPsec
＝ネットワーク層
＝IP通信を保護
＝暗号化・認証・改ざん検知
＝VPNで使用

AH
＝認証・完全性
＝暗号化しない

ESP
＝暗号化・認証・完全性

IKE
＝暗号鍵の交換・通信条件の協商
