# 関係演算

> [!summary] 一句話
> 選択取出資料列、射影取出欄位、結合依共同欄位合併多張表。

## 選択

> 符合條件的「行」取出來。

```text
選択＝選行
```

例如：

```text
販売日＝22/4/2 的資料
```

## 射影

> 取出需要的「列／欄位」。

```text
射影＝選列
```

例如：

```text
只保留販売ID、販売日
```

## 結合

> 透過共同欄位，把兩張表連接起來。

```text
結合＝連接資料表
```

例如：

```text
販売表＋商品表
→ 透過商品名連接
```

## 快速記憶

```text
選択＝選行
射影＝選列
結合＝連表
```

| 關係演算 | 中文 |
|---|---|
| 選択 | 取出特定的行 |
| 射影 | 取出特定的列 |
| 結合 | 連接兩張表 |
