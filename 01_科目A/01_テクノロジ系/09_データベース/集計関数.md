# 集計関数

> [!summary] 一句話
> SUM求合計、AVG求平均、COUNT計算筆數；注意COUNT星號與COUNT欄位對NULL的處理。

## 集計関数

用來計算資料。

## SUM

總和

例：

```sql
SUM(売上)
```

500 + 300 = 800

## AVG

平均值

例：

數量：

```
5
10
15
```

```sql
AVG(数量)
```

計算：

```
(5+10+15) ÷ 3

=10
```

## COUNT

計算筆數。

例如：

資料：

|商品|
|-|
|ペン|
|封筒|
|紙|

```sql
COUNT(*)
```

結果：

```
3
```

意思：

> 有幾筆資料。
