# GUIの代表的な部品

> [!summary] 一句話
> 單選用ラジオボタン、多選用チェックボックス；候選項目多時使用リスト或プルダウン。

## チェックボックス
- **用語：** Checkbox／複選框
- 每個項目都可以獨立勾選
- 可以同時選擇多個項目

例：

```text
☑ 音樂
☑ 電影
☐ 運動
```

關鍵詞：
```text
複数選択できる
```

## ラジオボタン
- **用語：** Radio Button／單選按鈕
- 從彼此互斥的選項中選擇一個
- 選擇新項目時，原本的選擇會取消

例：

```text
○ 現金
● 信用卡
○ 電子支付
```

關鍵詞：
```text
排他的な項目から一つ選ぶ
```

## プルダウンメニュー
- **用語：** Pull-down Menu／下拉式選單
- 點開清單後，從既有項目中選一個
- 不能自行輸入清單以外的內容

例：

```text
國家：日本 ▼
```

關鍵詞：
```text
一覧から一つ選ぶ
```

## コンボボックス
- **用語：** Combo Box／組合方塊
- 可以從清單中選擇
- 也可以自行輸入清單中沒有的內容

關鍵詞：
```text
選択または直接入力できる
```

## 比較
| **日文**    | **英文**         | **中文** | **可複選** | **可自行輸入** |
| --------- | -------------- | ------ | ------- | --------- |
| チェックボックス  | Checkbox       | 複選框    | 可以      | 不可以       |
| ラジオボタン    | Radio Button   | 單選按鈕   | 不可以     | 不可以       |
| プルダウンメニュー | Pull-down Menu | 下拉式選單  | 不可以     | 不可以       |
| コンボボックス   | Combo Box      | 組合方塊   | 不可以     | 可以        |

## FE考點
```text
Checkbox＝多選
Radio Button＝互斥單選
Pull-down Menu＝清單單選
Combo Box＝清單選擇＋自行輸入
```
