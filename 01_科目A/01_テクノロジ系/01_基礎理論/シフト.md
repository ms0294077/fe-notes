# シフト

> [!summary] 一句話
> 左移 n 位通常相當於乘 2^n；右移 n 位通常相當於除 2^n，但算術右移必須保留符號位。

## シフト是什麼？

シフト = 把二進位 bit 往左或往右移動。

```text
左シフト → × 2^n
右シフト → ÷ 2^n
```

## 論理シフト

不考慮正負號，單純移動 bit。

```text
空出來的位置一律補 0
```

例：

```text
00101100
右移 2 位
00001011
```

## 算術シフト

考慮正負號，通常用在 2 的補數。

### 左シフト

```text
空出來的位置補 0
```

### 右シフト

```text
空出來的位置補符號位
```

也就是：

```text
正數最高位是 0 → 補 0
負數最高位是 1 → 補 1
```

## 最重要比較

```text
論理右シフト：左邊補 0
算術右シフト：左邊補符號位
```

## 例：-24 算術右移 2 位

```text
-24 = 11101000
```

右移 2 位，因為是負數，所以左邊補 1：

```text
11101000
→ 11110100
→ 11111010
```

```text
11111010 = -6
```

所以：

```text
-24 >> 2 = -6
```

## 快速記憶

```text
論理シフト：空位補 0
算術シフト：右移時補符號位
```
