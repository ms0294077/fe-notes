# クラスの階層

> [!summary] 一句話
> 汎化・特化表示 is-a 關係；集約・分解表示 part-of 關係。

## 汎化・特化

### 汎化
多個下位類別抽出共同特徵，建立上位類別。

```text
バス・トラック・普通車 → 自動車
```
### 特化

將上位類別細分成更具體的下位類別。

```
自動車 → バス・トラック・普通車
```

- 關係：**is-a（是一種）**
- 例：バス is a 自動車
- 通常是父類別與子類別的繼承關係

## 集約・分解

### 集約

多個零件組合成一個整體。

```
アクセル・ブレーキ・ハンドル → 自動車
```

### 分解

將一個整體拆成多個組成部分。

```
自動車 → アクセル・ブレーキ・ハンドル
```

- 關係：**part-of（是一部分）**
- 例：ハンドル is part of 自動車

## 快速記憶

```
汎化・特化：is-a（是一種）
集約・分解：part-of（是一部分）
```
