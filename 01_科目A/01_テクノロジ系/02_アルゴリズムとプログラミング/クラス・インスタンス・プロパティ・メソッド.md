# クラス・インスタンス・プロパティ・メソッド

> [!summary] 一句話
> クラス是設計圖，インスタンス是依設計圖建立的實體；プロパティ保存狀態，メソッド定義行為。

## オブジェクト指向とは

**オブジェクト指向（Object-Oriented，物件導向）**是把程式中的人、物品等事物當成「物件」來管理的開發方式。

```text
オブジェクト ＝ データ ＋ 処理
物件 ＝ 資料 ＋ 功能
```
例如角色物件：

- データ：名字、HP、攻擊力
- 処理：攻擊、防禦、使用道具

## プロパティとメソッド

### プロパティ（Property，屬性）

物件所擁有的資料或狀態。

```
名字
HP
攻擊力
```

### メソッド（Method，方法）

物件可以執行的處理或動作。

```
攻擊
防禦
使用道具
```

## クラスとインスタンス

### クラス（Class，類別）

建立物件時使用的**設計圖**。

```
角色類別
├─ 名字
├─ HP
├─ 攻擊力
├─ 攻擊()
└─ 防禦()
```

### インスタンス（Instance，實例）

根據類別實際建立出來的物件。

```
クラス：角色的設計圖

インスタンス：
・勇者
・魔法師
・怪物
```

### 快速記憶

```
クラス ＝ 設計圖
インスタンス ＝ 根據設計圖建立的實體
オブジェクト ＝ 程式中的物件
```

FE考試中，インスタンス通常也可以理解為實際建立出的オブジェクト。
