# WAF

> [!summary] 一句話
> WAF 檢查 Web 應用層的 HTTP 通訊，用來防禦 XSS、SQLインジェクション等攻擊。

## WAF（Web Application Firewall）

Webアプリケーションへの通信内容を確認し、不正な攻撃を検知・遮断する仕組み。

中文：

> 專門保護網站與Web應用程式的防火牆。

## 主な防御対象

- SQLインジェクション
- クロスサイトスクリプティング（XSS）
- OSコマンドインジェクション
- 不正なHTTPリクエスト

## 仕組み

```text
利用者
↓
WAF
↓ 通信内容を検査
Webサーバ
```

正常な通信：

```text
WAFが通過させる
```

攻撃と判断した通信：

```text
WAFが遮断する
```

## ファイアウォールとの違い

| 項目 | ファイアウォール | WAF |
|---|---|---|
| 主な保護対象 | ネットワーク | Webアプリケーション |
| 確認内容 | IPアドレス、ポート番号など | HTTP通信や入力内容 |
| 防御例 | 不正な接続 | SQLインジェクション、XSS |

## 易錯點

WAFを導入しても、Webアプリケーションの脆弱性そのものが修正されるわけではない。

そのため：

- プログラムの脆弱性修正
- OSやソフトウェアの更新
- WAFによる防御

を組み合わせる必要がある。

## FE考點

```text
Webアプリケーションへの攻撃を防ぐ
→ WAF

SQLインジェクションやXSSを遮断
→ WAF

IPアドレスやポート番号で通信を制御
→ ファイアウォール
```

## 快速記憶

> WAF＝Webサイトの入口で、危険なHTTP通信を検査して止める仕組み。
