# 暗号方式の比較とハイブリッド暗号

> [!summary] 一句話
> 實際通訊常用公開鍵安全交換共通鍵，再用共通鍵高速加密大量資料。

## 兩種方式比較

| 項目 | 共通鍵暗号方式 | 公開鍵暗号方式 |
|---|---|---|
| 英文 | Symmetric-key Cryptography | Public-key Cryptography |
| 使用的鍵 | 同一把鍵 | 公開鍵與秘密鍵 |
| 暗号化 | 共通鍵 | 公開鍵 |
| 復号 | 同一把共通鍵 | 秘密鍵 |
| 鍵是否公開 | 不可公開 | 公開鍵可公開 |
| 處理速度 | 快 | 慢 |
| 計算量 | 小 | 大 |
| 大量資料 | 適合 | 不適合 |
| 鍵配送 | 困難 | 較容易 |
| 鍵管理 | 人數多時複雜 | 相對容易 |
| 代表方式 | AES、DES | RSA、ECC |

## ハイブリッド暗号方式（Hybrid Encryption）

實際的網路通訊通常會結合兩種方式，而不是只使用其中一種。

## 原因

- 公開鍵暗号方式
  → 可以安全交換鍵，但速度慢

- 共通鍵暗号方式
  → 速度快，但共通鍵難以安全傳送

因此結合兩者：

```text
① 使用公開鍵暗号方式安全傳送共通鍵
② 使用共通鍵暗号方式加密實際資料
```

## 通訊流程

```text
接收者公開自己的公開鍵
↓
發送者產生共通鍵
↓
使用接收者的公開鍵加密共通鍵
↓
接收者使用自己的秘密鍵取得共通鍵
↓
雙方使用共通鍵傳送大量資料
```

這種方式同時取得：

- 公開鍵暗号方式的安全鍵交換
- 共通鍵暗号方式的高速處理

HTTPS等安全通訊會使用類似的混合方式。

## FE考點

```text
暗号化和復号使用同一把鍵
→ 共通鍵暗号方式

公開鍵和秘密鍵兩把不同的鍵
→ 公開鍵暗号方式

速度快、適合大量資料
→ 共通鍵暗号方式

鍵配送困難
→ 共通鍵暗号方式

公開鍵可以公開
→ 公開鍵暗号方式

處理速度較慢
→ 公開鍵暗号方式

AES
→ 共通鍵暗号方式

RSA
→ 公開鍵暗号方式

公開鍵方式交換共通鍵，再用共通鍵傳資料
→ ハイブリッド暗号方式
```

## 快速記憶

```text
共通鍵暗号方式
→ 同一把鍵
→ 速度快
→ 但交付秘密鍵很麻煩

公開鍵暗号方式
→ 公開鍵＋秘密鍵
→ 鍵容易安全提供
→ 但處理速度較慢
```
