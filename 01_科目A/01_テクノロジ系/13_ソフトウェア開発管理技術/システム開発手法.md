# システム開発手法

> [!summary] 一句話
> ウォータフォール依序完成各階段；プロトタイピング先做雛形；スパイラル反覆開發與風險分析。

## ウォーターフォール
- **用語：** Waterfall／瀑布式開發
- 依照需求、設計、開發、測試的順序進行
- 前一階段完成後，再進入下一階段
- 適合需求明確、變更少的大型系統
- 缺點是中途修改需求較困難

關鍵詞：
```text
上流工程から下流工程へ順番に進める
```

## アジャイル
- **用語：** Agile／敏捷開發
- 以短週期反覆進行開發
- 每次完成一部分可使用功能
- 持續接受使用者回饋
- 適合需求容易改變的系統

關鍵詞：
```text
短い開発サイクルを繰り返す
```

## プロトタイピングモデル
- **用語：** Prototyping Model／原型開發模型
- 先製作試作品
- 讓使用者實際確認畫面與操作
- 根據意見修正需求
- 適合需求不明確、UI重要的系統

關鍵詞：
```text
試作品を作成して要求を確認する
```

## リバースエンジニアリング
- **用語：** Reverse Engineering／逆向工程
- 分析現有程式或系統
- 從程式碼反推出設計與規格
- 常用於沒有文件的舊系統
- 主要目的不是開發新功能，而是理解現有系統

關鍵詞：
```text
既存プログラムから設計情報を抽出する
```

## 比較
|**開發手法**|**中文**|**核心**|
