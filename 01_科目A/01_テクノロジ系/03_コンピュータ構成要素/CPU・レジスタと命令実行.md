# CPU・レジスタと命令実行

> [!summary] 一句話
> CPU由演算裝置、制御装置與レジスタ構成；指令依取出、解碼、執行的順序處理。

## CPU、レジスタ、アドレス指定方式

## CPU 的基本構成

### 演算装置
- **ALU**：加減、比較、AND、OR 等運算
- **汎用レジスタ**：暫存資料或運算結果

### 制御装置
- **プログラムカウンタ**：指向下一條指令
- **命令レジスタ**：保存當前指令
- **デコーダー**：解讀指令

## レジスタ簡介

| 名稱             | 功能                     |
|------------------|--------------------------|
| プログラムカウンタ | 保存下一條指令位址         |
| 命令レジスタ       | 保存當前指令             |
| インデックスレジスタ | 保存偏移量，用於陣列或表格 |
| ベースレジスタ      | 保存程式或資料區域起始位址 |
| アキュムレータ      | 保存運算對象或結果       |
| 汎用レジスタ       | 通用暫存器，可存放各種資料 |

## CPU 執行指令流程

1. **取指令**：プログラムカウンタ指出位置，從記憶體取出指令。
2. **解讀**：指令放入命令レジスタ，デコーダー解讀。
3. **執行**：ALU 或其他裝置執行，結果存入レジスタ或メモリ。

## 指令結構

- **命令部**：操作類型（如 ADD、SUB、LOAD、JUMP）
- **オペランド部**：操作對象或資料位置（如記憶體位址、暫存器）

## レジスタ功能區別

| 名稱             | 功能                     |
|------------------|--------------------------|
| プログラムカウンタ | 下一條指令位址             |
| 命令レジスタ       | 當前指令內容             |
| ベースレジスタ      | 程式或資料區域起始位址     |
| インデックスレジスタ | 偏移量，用於陣列或表格     |
| アキュムレータ      | 運算對象或結果           |

## FE 必背重點

- **プログラムカウンタ**：下一條指令在哪裡
- **命令レジスタ**：目前指令是什麼
- **ベースレジスタ**：程式或資料起點
- **インデックスレジスタ**：從資料起點移動多少
- **命令部**：要做什麼操作
