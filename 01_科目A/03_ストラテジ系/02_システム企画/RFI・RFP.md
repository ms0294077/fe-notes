# RFI・RFP

> [!summary] 一句話
> RFI 用來廣泛收集供應商資訊；RFP 提出具體需求並要求供應商提交提案。
## RFI
- **用語：** Request for Information
中文：**資訊提供依賴書／資訊徵詢書**

### 目的
向多家廠商蒐集一般性資訊，例如：

- 有哪些產品或服務
- 使用什麼技術
- 過去有哪些導入案例
- 大概的價格與時程
- 廠商是否具備開發能力

### 使用時機
- 公司需求還不夠明確
- 想先了解市場上有哪些方案
- 用來初步篩選廠商

```text
RFI＝你們有什麼？
```

## RFP
- **用語：** Request for Proposal
中文：**提案依賴書／提案邀請書**

### 目的
把較明確的需求交給廠商，要求提出具體方案，例如：

- 系統設計方式
- 使用的技術
- 開發時程
- 人員配置
- 報價
- 維護方式

### 使用時機
- 公司已經整理出具體需求
- 想比較不同廠商的方案
- 用來選出最後合作的廠商

```text
RFP＝你們打算怎麼做？
```

## RFI 與 RFP 比較
|**項目**|**RFI**|**RFP**|
|---|---|---|
|中文|資訊徵詢書|提案邀請書|
|目的|蒐集一般資訊|要求具體方案|
|需求狀態|尚未完全明確|已經較明確|
|廠商回答|能提供什麼|要如何實現|
|階段|前期調查|廠商評選|
|審查|一次審查|二次審查|

## 流程
```text
發現需求
→ 發出 RFI
→ 蒐集資訊、初步篩選廠商
→ 發出 RFP
→ 比較具體提案
→ 選定廠商
```

## FE考點
```text
RFI：Information＝收集資訊
RFP：Proposal＝要求提案
```

```text
RFI＝有什麼？
RFP＝怎麼做？
```
