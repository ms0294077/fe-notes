# PMBOKの10個の知識エリア

> [!summary] 一句話
> 傳統PMBOK的十個知識領域涵蓋統合、範囲、時間、成本、品質、資源、溝通、風險、採購與利害關係人。

## 十個領域

| 領域 | 管理對象 |
|---|---|
| 統合管理 | 整合整個專案與變更 |
| スコープ管理 | 要做什麼、不做什麼 |
| スケジュール管理 | 活動、順序與工期 |
| コスト管理 | 預算與費用 |
| 品質管理 | 成果與流程品質 |
| 資源管理 | 人員、設備與團隊 |
| コミュニケーション管理 | 資訊的產生、傳遞與保存 |
| リスク管理 | 不確定事件與應對 |
| 調達管理 | 外部採購與契約 |
| ステークホルダー管理 | 利害關係人的期待與參與 |

## 容易混淆

- 作業是否在專案範圍內：スコープ
- 何時完成：スケジュール
- 需要多少錢：コスト
- 發生機率與影響：リスク
- 委外與契約：調達
- 誰受影響、如何取得支持：ステークホルダー

## 統合管理

統合管理負責協調其他領域，並處理整體変更管理。題目出現「專案全體」「整合」「変更要求」時優先考慮統合。

## FE考點

- WBS主要屬スコープ管理
- クリティカルパス主要屬スケジュール管理
- 品質管理與範圍驗收不是同一件事
- 溝通問題不一定是ステークホルダー問題，要看題目目的

## 注意

PMBOK新版的呈現方式已有變化，但FE題庫仍可能以傳統五個プロセス群與十個知識領域出題，應依題目用語回答。
