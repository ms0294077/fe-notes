# 変更・リリース・構成管理

> [!summary] 一句話
> 変更管理控制變更風險，リリース管理部署版本，構成管理掌握CI及其關係。

## 変更管理
- **用語：** Change Management／變更管理
對系統的變更進行：

- 申請
- 影響分析
- 風險評估
- 批准
- 排程
- 實施後確認

例如：

- 修改防火牆設定
- 更新資料庫
- 更換伺服器
- 修改系統功能

目的：

防止未經控制的變更造成新的故障。

## リリース管理
- **用語：** Release Management／發布管理
負責將新的或修改後的內容正式發布到使用環境。

例如：

- 新版軟體
- 修補程式
- 新功能
- 系統設定

```text
Change Management
＝決定變更可不可以做、何時做

Release Management
＝實際將新版發布出去
```

## 構成管理
- **用語：** Configuration Management／組態管理、配置管理
管理IT服務中的構成項目及其關係。

### 構成項目
- **用語：** CI = Configuration Item／組態項目
例如：

- 伺服器
- 電腦
- 軟體版本
- 資料庫
- 網路設備
- 合約
- IP位址

### CMDB
- **用語：** Configuration Management Database／組態管理資料庫
記錄：

- 有哪些設備與軟體
- 使用哪個版本
- 放在哪裡
- 負責人是誰
- 各項目之間的依賴關係
