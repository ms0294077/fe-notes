# サービスデスク・インシデント・サービス要求

> [!summary] 一句話
> インシデント管理優先恢復服務；服務要求是密碼重設、資訊提供等標準請求。

## 核心概念

**日々のサービス運用**是指：

> IT服務上線後，每天持續處理使用者詢問、故障、服務申請與系統維護。

使用者通常先聯絡：

- **用語：** サービスデスク（Service Desk，服務台）
服務台是IT服務使用者與提供者之間的：

> 單一聯絡窗口。

## サービスデスクの役割

主要受理：

- 系統無法使用
- 處理速度變慢
- 不知道操作方法
- 忘記密碼
- 帳號或權限申請
- 使用者抱怨與詢問

## インシデント管理

- **用語：** Incident Management／事件管理
### インシデントとは

**インシデント（Incident）**是指：

> IT服務中斷，或服務品質下降的事件。

例如：

- 系統無法登入
- 網路斷線
- 系統速度異常緩慢
- 郵件無法寄送
- App無法啟動

### 目的

> 儘快恢復正常服務，降低對業務與使用者的影響。

此階段不一定要立刻找出根本原因，而是優先恢復使用。

```text
インシデント管理
＝先恢復服務
＝先救火
```

## サービス要求管理
- **用語：** Service Request Management／服務請求管理
### サービス要求とは
服務本身沒有故障，但使用者要求標準服務或協助。

例如：

- 忘記密碼，希望重設
- 不知道登入方法
- 申請帳號
- 申請系統權限
- 申請安裝軟體
- 詢問使用方法

```text
服務壞掉、變慢
→ Incident

服務正常，但想申請或詢問
→ Service Request
```
