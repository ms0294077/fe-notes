# 問題管理・既知のエラー

> [!summary] 一句話
> 問題管理追查根本原因；已分析且有因應方式的問題記錄為既知のエラー。

## 問題管理
- **用語：** Problem Management／問題管理
目的：

找出一個或多個Incident背後的根本原因，避免再次發生。

例如：

```text
系統每天早上都變慢
```

- Incident Management：重新啟動，先恢復速度
- Problem Management：調查後發現資料庫設計問題並修正

```text
Incident＝先救火
Problem＝找出為什麼一直失火
```

## 既知のエラーDB
- **用語：** KEDB = Known Error Database／已知錯誤資料庫
保存：

- 已知問題
- 問題原因
- 暫時解決方法
- 過去處理紀錄

Incident發生時，可以先查KEDB，快速找到處理方式。
