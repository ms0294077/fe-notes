# 内部統制・職務分離

> [!summary] 一句話
> 內部控制以制度降低錯誤與舞弊；職務分離避免一人獨自完成互相牽制的工作。

## 内部統制
- **用語：** Internal Control／內部控制
由經營者建立公司內部的規則、流程與檢查機制，防止員工犯錯、舞弊或業務失控。

例如：

- 付款申請與批准由不同人負責
- 高額支出必須經主管核准
- 系統權限按照職務分配
- 定期盤點庫存
- 保留系統操作紀錄
- 重要資料定期備份
- 禁止同一人同時負責記帳與付款

基本關係：

```text
経営者
→ 管理・監督
→ 従業員・業務プロセス
```

重點：公司內部建立規則，防止錯誤與舞弊。

## 兩者差別
|**項目**|**コーポレートガバナンス**|**内部統制**|
|---|---|---|
|英文|Corporate Governance|Internal Control|
|中文|公司治理|內部控制|
|主要對象|經營者與整體企業|員工與內部業務流程|
|誰來監督|股東、董事會、監査役等|經營者與管理層|
|範圍|整體企業經營|具體內部作業與流程|
|主要目的|防止經營者亂來|防止員工舞弊與作業錯誤|

## 兩者關係
**Corporate Governance** 是較大的概念。

**Internal Control** 是實現良好公司治理的重要方法之一。

```text
コーポレートガバナンス
└─ 内部統制
   ├─ 權限管理
   ├─ 職務分離
   ├─ 承認流程
   ├─ 紀錄保存
   └─ 定期檢查
```

## 職務分離
- **用語：** Segregation of Duties／職務分離
將重要業務分給不同人負責，避免一個人能夠自行完成並隱藏舞弊。

錯誤例：

```text
同一個人
→ 申請付款
→ 批准付款
→ 實際付款
→ 記帳
```

適當例：

```text
員工A：申請
員工B：批准
員工C：付款
員工D：記帳與核對
```

這是內部控制的常見考點。
