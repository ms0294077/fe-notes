# アプリケーション層の主要プロトコル

> [!summary] 一句話
> 依用途記住 Web、檔案、郵件、名稱解析、位址設定與監視協定及其代表埠號。

## 主要プロトコル

| 協定 | 用途 | 代表ポート |
|---|---|---:|
| HTTP | Web通訊 | 80 |
| HTTPS | TLS保護的Web通訊 | 443 |
| FTP | 檔案傳送 | 20／21 |
| SSH | 安全遠端登入 | 22 |
| TELNET | 未加密遠端登入 | 23 |
| SMTP | 郵件傳送 | 25 |
| DNS | 名稱解析 | 53 |
| DHCP | 自動配發網路設定 | 67／68 |
| POP3 | 把郵件下載到用戶端 | 110 |
| IMAP | 在伺服器上管理郵件 | 143 |
| SNMP | 網路設備監視 | 161／162 |

埠號是典型預設值，實際系統可能使用其他埠。

## 郵件流程

- 送信：SMTP
- サーㄊ間轉送：SMTP
- 受信並下載：POP3
- 受信並在server同步管理：IMAP

## FTP的兩條連線

- 21番：控制連線
- 20番：主動模式的資料連線

被動模式的資料埠會由伺服器另行通知，不一定是20番。

## DNS與DHCP

- DNS：把domain name解析成IP address
- DHCP：配發IP、subnet mask、default gateway、DNS server等設定

## SNMP

- マネージャ：監視端
- エージェント：被監視設備
- MIB：保存管理資訊
- Trap：設備主動通知事件

## FE考點

- Web：HTTP／HTTPS
- 寄信：SMTP
- 收信：POP3／IMAP
- 名稱解析：DNS
- 自動設定：DHCP
- 網路監視：SNMP
- 安全遠端操作：SSH

## 易錯點

- DNS不是配發IP；DHCP不是解析名稱
- HTTPS不是獨立於HTTP的應用，而是HTTP over TLS
- TELNET與FTP的認證資料通常不加密

## 快速記憶

> Web 80／443、SSH 22、SMTP 25、DNS 53，是最常見的基本組合。
