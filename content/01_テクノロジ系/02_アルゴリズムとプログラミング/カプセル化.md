# カプセル化

> [!summary] 一句話
> 把資料與操作封裝在物件內，限制外部直接存取以降低相依與誤操作。

## カプセル化

**カプセル化（Encapsulation，封裝）**是隱藏物件內部的資料，不允許外部直接隨意修改，只能透過指定的方法操作。

例如角色資料：

```
最大HP：150
現在HP：120
```

如果可以直接修改：

```
現在HP = 170
現在HP = -80
```

就會產生不合理的數值。

封裝後，只能透過方法修改：

```
HPを回復する
ダメージを受ける
```

方法內部會進行檢查：

```
HP不能超過150
HP不能低於0
```

### 目的

- 保護資料
- 防止不合理的數值
- 降低程式錯誤

### 快速記憶

```
カプセル化：
資料不能從外部直接亂改，
只能透過指定的方法修改。
```
