# インタプリタとコンパイラ

> [!summary] 一句話
> インタプリタ逐句翻譯並執行；コンパイラ先把整個程式翻譯成目的程式再執行。

## 基本概念

電腦無法直接理解人類撰寫的高水準語言，因此需要把程式翻譯成機械語後才能執行。

主要有兩種翻譯方式：

1. インタプリタ（Interpreter，直譯器）
2. コンパイラ（Compiler，編譯器）

## インタプリタ（Interpreter，直譯器）

一邊翻譯程式，一邊執行。

```text
原始程式 → 逐行翻譯 → 立即執行
```
### 特徵

- 不需要事先將整個程式翻譯完成
- 修改程式後可以立即執行
- 容易進行測試與除錯
- 每次執行時都需要再次翻譯
- 一般執行速度較慢
- 通常執行到錯誤位置時才發現錯誤

### 代表語言

- Python
- JavaScript

### 白話理解

像「同步口譯」：

> 聽一句、翻譯一句、執行一句。

## コンパイラ（Compiler，編譯器）

先把整個原始程式一次翻譯成機械語，再執行翻譯完成的程式。

```
原始程式 → 全部編譯 → 目的程式 → 執行
```

### 特徵

- 執行前需要先進行編譯
- 可以在編譯階段檢查整個程式的錯誤
- 編譯完成後通常不需要每次重新翻譯
- 執行速度通常比直譯方式快
- 修改原始程式後，需要重新編譯

### 代表語言

- C
- C++
- Java（FE考試通常歸類於編譯型）

### 白話理解

像「整篇文件翻譯」：

> 先把整份內容全部翻譯完成，再交給電腦執行。

## 兩者比較

|比較項目|インタプリタ|コンパイラ|
|---|---|---|
|中文|直譯器|編譯器|
|翻譯方式|一邊翻譯一邊執行|整個程式一次翻譯|
|執行前處理|較少|需要先編譯|
|執行速度|通常較慢|通常較快|
|修改後|可以立即執行|通常需要重新編譯|
|錯誤發現|執行到該處才發現|編譯時統一檢查|
|代表語言|Python、JavaScript|C、C++、Java|

## FE考點

```
逐行翻譯、邊翻譯邊執行
→ インタプリタ

整個程式一次翻譯成機械語
→ コンパイラ
```

### 快速記憶

- インタプリタ：翻一句，跑一句
- コンパイラ：全部翻完，再開始跑
