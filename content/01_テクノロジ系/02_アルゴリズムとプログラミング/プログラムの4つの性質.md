# プログラムの4つの性質

> [!summary] 一句話
> FE 常從正当性、可読性、保守性、移植性判斷程式品質。

## リロケータブル（Relocatable，可重定位）

程式不論被配置在主記憶體的哪個位置，都可以正常執行。

```
放在哪裡都能跑
```

- 主記憶體中的配置位置可以改變
- 位址改變後仍可執行

## リユーザブル（Reusable，可重複使用）

程式載入主記憶體一次後，不需要重新載入，就可以反覆執行。

```
載入一次，可以重複使用
```

- 上一次執行結束後，可以再次使用
- 不一定可以被多個任務同時使用

## リエントラント（Reentrant，可重入）

同一個程式可以同時被多個タスク（Task，任務）呼叫並執行，而且不會互相影響。

```
多個任務可以同時使用
```

通常：

- 程式碼部分可以共用
- 每個任務的變數、資料需要分開保存

## リカーシブ（Recursive，遞迴）

程式或函式在執行過程中，可以呼叫自己。

```
自己呼叫自己
```

例如：

```
factorial(5)
→ 5 × factorial(4)
→ 5 × 4 × factorial(3)
```

遞迴必須設定結束條件，否則會一直呼叫下去。

## リユーザブル與リエントラント的差別

### リユーザブル

```
任務A使用完 → 任務B再使用
```

可以反覆使用，但不保證能同時使用。

### リエントラント

```
任務A使用中
任務B也可以同時使用
```

重點是多個任務能夠安全地同時執行同一個程式。

## 快速記憶

|性質|中文|記憶方式|
|---|---|---|
|リロケータブル|可重定位|放哪裡都能跑|
|リユーザブル|可重複使用|載入一次，重複使用|
|リエントラント|可重入|多個任務同時使用|
|リカーシブ|遞迴|自己呼叫自己|

## FE考點

```
位置可以改變 → リロケータブル
不用重新載入 → リユーザブル
多個任務同時呼叫 → リエントラント
自己呼叫自己 → リカーシブ
```
