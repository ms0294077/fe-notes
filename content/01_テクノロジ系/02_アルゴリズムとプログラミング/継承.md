# 継承

> [!summary] 一句話
> 子類別繼承父類別的屬性與方法，並可追加或覆寫功能。

## 継承

**継承（Inheritance，繼承）**是讓新類別繼承既有類別的屬性與方法。

### スーパークラス（Superclass，父類別）

作為基礎、被其他類別繼承的類別。

例如：

```
角色類別
├─ 名字
├─ HP
├─ 攻擊力
├─ 攻擊()
└─ 防禦()
```

### サブクラス（Subclass，子類別）

繼承父類別後建立的新類別。

```
主人公類別
├─ 繼承：名字、HP、攻擊力、攻擊、防禦
└─ 新增：使用道具

敵人類別
├─ 繼承：名字、HP、攻擊力、攻擊、防禦
└─ 新增：逃跑
```

### 優點

共同的內容只需要寫一次，子類別可以直接使用，再加入自己特有的功能。

### 快速記憶

```
スーパークラス ＝ 親類別
サブクラス ＝ 子類別
継承 ＝ 子類別繼承父類別的資料與功能
```
