# パイプライン・スーパースカラ

> [!summary] 一句話
> パイプライン重疊各階段，スーパーパイプライン細分階段，スーパースカラ同時執行多條指令。

## CPU高速化

## パイプライン

一條命令的處理通常分成：

命令取出
→ 命令解讀
→ オペランド讀取
→ 命令執行

パイプライン方式會讓多條命令的不同階段同時進行，提高處理效率。

例：

時間1：A取出
時間2：A解讀＋B取出
時間3：A讀取＋B解讀＋C取出

重點：

パイプライン
＝多條命令重疊處理

## スーパーパイプライン

把命令處理階段切得更細，提高パイプライン效率。

例：

原本：

取出
→ 解讀
→ 執行

細分後：

取出1
→ 取出2
→ 解讀1
→ 解讀2
→ 執行1
→ 執行2

重點：

スーパーパイプライン
＝一條パイプライン切得更細

## スーパースカラ

CPU 內部設置多條パイプライン，同時執行多條命令。

重點：

スーパースカラ
＝多條パイプライン並行處理

注意：

- スーパーパイプライン：切細
- スーパースカラ：增加條數
