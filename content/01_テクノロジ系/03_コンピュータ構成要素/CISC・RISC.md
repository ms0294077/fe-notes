# CISC・RISC

> [!summary] 一句話
> CISC重複雜多功能指令，RISC重簡單固定長度指令與高速流水線。

## CISC

CISC
＝Complex Instruction Set Computer

一條命令可以完成較複雜的處理。

特徵：

- 命令較複雜
- 一條命令能做很多事
- 程式的命令數較少
- 每條命令的執行時間容易不同
- 不利於パイプライン處理

簡單記：

CISC
＝複雜命令、命令數少

## RISC

RISC
＝Reduced Instruction Set Computer

使用簡單且功能單一的命令。

特徵：

- 命令簡單
- 一條命令只做較單純的處理
- 程式的命令數較多
- 命令執行時間較一致
- 適合パイプライン處理
- 每條命令容易高速執行

簡單記：

RISC
＝簡單命令、命令數多、適合パイプライン
