# ストアドプロシージャ

> [!summary] 一句話
> 把常用 SQL 處理預先保存在DB伺服器，可減少通訊並統一處理，但會提高DB依賴。

## 定義

**ストアドプロシージャ（Stored Procedure，儲存程序）**是：

> 將常用的一組 SQL 指令預先保存在 DBMS 中，需要時直接呼叫執行。

可以理解成：

> 存在資料庫裡的 SQL 函式包。

## 例子

原本轉帳需要執行多條 SQL：

```text
確認餘額
↓
扣除轉出帳戶金額
↓
增加轉入帳戶金額
↓
寫入交易紀錄
```

把這些處理包成一個儲存程序後，應用程式只需要呼叫一次：

```sql
CALL transfer_money(...);
```

## 優點

- 減少應用程式和資料庫之間的通訊次數
- 降低網路負擔
- 提高處理速度
- 同一組 SQL 可以重複使用

## FE考點

```text
ストアドプロシージャ
＝常用的多條SQL預先保存在DBMS中
＝呼叫一次即可執行整組處理
＝降低網路負擔
＝提高處理速度
```

注意：

```text
保存在DBMS端
不是保存在應用程式端
```
