# 仮想記憶の基本

> [!summary] 一句話
> 仮想記憶讓程式可使用比主記憶更大的位址空間，實際資料按需在主記憶與輔助記憶間交換。

## 仮想記憶とは
- English：Virtual Memory
- 中文：虛擬記憶體
- OS 建立一個看起來比實際 RAM 更大的記憶體空間
- 程式的一部分可以放在 RAM，其他部分則放在 SSD／HDD
- 程式不需要知道資料實際放在哪個裝置或位置

## 実記憶
- English：Physical Memory／Real Memory
- 中文：實體記憶體
- 指實際存在的主記憶裝置，也就是 RAM
- 容量受到實際硬體限制

## 仮想記憶的實際構造

程式看到的情況：

一大片連續的虛擬記憶體空間

實際情況：

- 一部分資料在 RAM
- 一部分資料在 SSD／HDD
- 由 OS 負責管理資料的位置與移動

## 仮想アドレス
- English：Virtual Address
- 中文：虛擬位址
- 程式執行時所使用的位址
- 程式不需要知道資料在 RAM 中的真正位置

## 物理アドレス
- English：Physical Address
- 中文：實體位址／物理位址
- 資料在 RAM 中真正存放的位置

## 動的アドレス変換機構
- English：Dynamic Address Translation
- 簡稱：DAT
- 中文：動態位址轉換機制
- 負責將仮想アドレス轉換成物理アドレス

## メモリ管理ユニット
- English：Memory Management Unit
- 簡稱：MMU
- 中文：記憶體管理單元
- 負責進行位址轉換的硬體

## 位址轉換流程

程式
↓ 使用仮想アドレス
MMU／DAT
↓ 轉換位址
物理アドレス
↓
存取 RAM 中的真正位置

## 仮想記憶的優點
- 可以執行容量大於實際 RAM 的程式
- 程式不需要自己管理真正的記憶體位置
- 每個程式可以擁有獨立的位址空間
- 比較容易防止不同程式互相破壞記憶體內容
- OS 可以根據需要在 RAM 和 SSD／HDD 之間移動資料

## 快速記憶
- 仮想アドレス：程式看到的位址
- 物理アドレス：RAM 中真正的位址
- MMU／DAT：把虛擬位址轉換成實體位址
- 仮想記憶：讓程式看起來擁有比實際 RAM 更大的空間
