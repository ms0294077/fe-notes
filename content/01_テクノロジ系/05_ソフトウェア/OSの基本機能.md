# OSの基本機能

> [!summary] 一句話
> OS 管理 CPU、記憶體、檔案與輸入輸出裝置，並提供應用程式共通的執行環境。

OS 的主要工作是管理電腦資源。

## ジョブ・タスク管理
- 管理 CPU 要執行哪一個工作
- 決定執行順序與使用時間
- 讓多個程式看起來能同時執行

## 記憶管理
- 管理主記憶體 RAM
- 決定程式使用哪一塊記憶體
- 程式執行前會從 SSD／HDD 載入 RAM

## ファイル管理
- 管理檔案與資料夾
- 負責建立、讀取、儲存、移動與刪除
- 管理檔案位置與存取權限

## 快速記憶
- CPU：ジョブ・タスク管理
- RAM：記憶管理
- SSD／HDD：ファイル管理
