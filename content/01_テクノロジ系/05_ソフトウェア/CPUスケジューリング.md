# CPUスケジューリング

> [!summary] 一句話
> CPU 排程方法依到達順序、處理時間、優先度或時間片決定下一個執行的タスク。

CPUスケジューリング是決定哪個 Task 先使用 CPU。

## 到着順方式
- 英文：FCFS
- First Come, First Served
- 先進入実行可能状態的 Task 先執行
- 通常是ノンプリエンプティブ方式

例：

A → B → C

缺點：

前面的 Task 很長時，後面的 Task 要一直等待。

## 優先順方式
- 優先順位較高的 Task 先使用 CPU
- 通常是プリエンプティブ方式

例：

高優先 → 中優先 → 低優先

缺點：

低優先級 Task 可能長期無法執行。

這種情況稱為スタベーション。

## ラウンドロビン方式
- 英文：Round Robin
- 中文：輪轉排程
- 每個 Task 輪流使用固定時間
- 屬於プリエンプティブ方式

例：

A → B → C → A → B → C

固定的執行時間稱為：

- タイムスライス
- タイムクォンタム

缺點：

切換太頻繁會增加コンテキストスイッチ的負擔。

## プリエンプティブ方式
- 英文：Preemptive
- OS 可以中途中斷 Task
- 把 CPU 分配給其他 Task

例：

- 優先順方式
- ラウンドロビン方式

## ノンプリエンプティブ方式
- 英文：Non-preemptive
- OS 不會中途強制搶走 CPU
- 要等 Task 執行完成或進入待機狀態

例：

- 到着順方式

## 比較

| 方式 | 判斷方法 | 類型 |
|---|---|---|
| 到着順方式 | 先來先做 | ノンプリエンプティブ |
| 優先順方式 | 重要的先做 | 通常プリエンプティブ |
| ラウンドロビン方式 | 每人輪流固定時間 | プリエンプティブ |

## 快速記憶
- 到着順：誰先來誰先做
- 優先順：誰重要誰先做
- Round Robin：大家輪流做
