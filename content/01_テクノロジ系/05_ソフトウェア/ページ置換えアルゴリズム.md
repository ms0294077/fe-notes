# ページ置換えアルゴリズム

> [!summary] 一句話
> FIFO換最早載入的頁，LRU換最久未使用的頁，LFU換使用次數最少的頁。

## 使用時機

ページフォールト發生且主記憶沒有空frame時，OS必須選一頁移出。

## 演算法比較

| 演算法 | 被換出的頁 | 需要的資訊 |
|---|---|---|
| FIFO | 最早載入 | 進入順序 |
| LIFO | 最後載入 | 進入順序 |
| LRU | 最久未使用 | 最近使用時間 |
| LFU | 使用次數最少 | 參照次數 |
| OPT | 未來最久不會使用 | 未來參照序列 |

## FIFO

容易實作，但可能發生Belady異常：frame增加，page fault反而增加。

## LRU

利用時間的局所性，通常比FIFO合理，但要記錄使用順序或近似資訊。

## LFU

保留使用頻率高的頁面，但很久以前累積的高次數可能使頁面不易被換出。

## OPT

理論上page fault最少，用來比較其他演算法，但實際系統無法預知未來。

## 解題方法

1. 畫出每個frame
2. 依序讀取page reference
3. page已在frame中：hit，不置換
4. 不在且有空位：直接載入
5. 不在且無空位：依演算法置換
6. 累計page fault次數

## FE考點

- 最早進入：FIFO
- 最近最久沒用：LRU
- 使用次數最少：LFU
- 理論最佳：OPT
- Belady異常：FIFO

## 易錯點

- LRU看「時間」，LFU看「次數」
- 同次數或同時間時，要依題目指定的tie-break規則
- 初次載入空frame也算page fault

## 快速記憶

> FIFO看進門順序，LRU看最後使用時間，LFU看累計次數。
