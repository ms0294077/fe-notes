# ディレクトリ構造

> [!summary] 一句話
> ルート、親、子、カレント、ホームディレクトリ的差異是常見考點。

## ファイル管理とは
- OS 負責管理ファイル（File，檔案）與ディレクトリ（Directory，目錄／資料夾）
- 主要工作包括：
  - 建立、讀取、寫入與刪除檔案
  - 管理資料夾階層
  - 記錄檔案存放位置
  - 管理檔案名稱與存取權限

## ディレクトリとファイル

### ディレクトリ
- English：Directory
- 中文：目錄／資料夾
- 用來集中管理多個檔案與其他目錄
- 與フォルダ（Folder，資料夾）基本上是同一個意思

### ファイル
- English：File
- 中文：檔案
- 實際儲存資料的單位
- 例：圖片、文件、程式、音樂

### 階層構造
目錄可以包含其他目錄與檔案，形成樹狀的階層結構。

例：

旅行写真
├─ 北海道
│  ├─ 写真1
│  └─ 予備
│     └─ 写真2
└─ 関西
   ├─ 大阪
   └─ 京都

## 重要なディレクトリ

### カレントディレクトリ
- English：Current Directory
- 中文：目前目錄／當前目錄
- 現在所在的目錄

### 親ディレクトリ
- English：Parent Directory
- 中文：父目錄／上一層目錄
- 目前目錄的上一層
- 通常用 `..` 表示

### サブディレクトリ
- English：Subdirectory
- 中文：子目錄
- 位於某個目錄內的下一層目錄

### ルートディレクトリ
- English：Root Directory
- 中文：根目錄
- 整個目錄階層的最上層
- Linux／macOS 通常用 `/` 表示

### ホームディレクトリ
- English：Home Directory
- 中文：使用者主目錄／家目錄
- 使用者登入後預設所在的個人目錄
- Linux／macOS 常用 `~` 表示

## 易錯點
- ルートディレクトリ：整個系統最上層
- ホームディレクトリ：某個使用者自己的目錄
