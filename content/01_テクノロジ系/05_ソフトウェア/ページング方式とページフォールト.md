# ページング方式とページフォールト

> [!summary] 一句話
> 仮想頁不在主記憶時發生ページフォールト，OS 必須從輔助記憶載入頁面。

## ページング方式
- English：Paging
- 中文：分頁式記憶體管理
- 將虛擬記憶體空間與 RAM 分割成固定大小的小區塊
- 執行程式時，只將目前需要的部分載入 RAM
- 不需要一次把整個程式載入 RAM

## ページ
- English：Page
- 中文：頁／頁面
- 虛擬記憶體被切割後的固定大小區塊

## ページフレーム
- English：Page Frame
- 中文：頁框
- RAM 中用來存放ページ的固定大小區域
- ページ和ページフレーム的大小相同

## ページテーブル
- English：Page Table
- 中文：頁表
- 記錄每一個ページ目前放在哪一個ページフレーム
- 也會記錄該ページ目前是否存在於 RAM

例：

| 仮想ページ | 實際狀態 |
|---|---|
| Page 1 | 位於 Frame 3 |
| Page 2 | 不在 RAM |
| Page 3 | 位於 Frame 1 |

## デマンドページング
- English：Demand Paging
- 中文：需求分頁
- 只有當某個ページ真的被使用時，才將它載入 RAM
- 尚未使用的ページ可以繼續留在 SSD／HDD

## ページフォールト
- English：Page Fault
- 中文：缺頁中斷／頁面錯失
- CPU 要使用的ページ目前不在 RAM 時發生
- 這不一定代表程式出錯，而是通知 OS 需要先載入該ページ

## ページフォールト發生流程

CPU 要存取某個ページ
↓
查看ページテーブル
↓
發現該ページ不在 RAM
↓
發生ページフォールト
↓
從 SSD／HDD 找到該ページ
↓
將該ページ載入 RAM
↓
更新ページテーブル
↓
重新執行剛才的指令

## ページイン
- English：Page-in
- 中文：頁面換入
- 將ページ從 SSD／HDD 載入 RAM

SSD／HDD
↓ ページイン
RAM

## ページアウト
- English：Page-out
- 中文：頁面換出
- 將 RAM 中的ページ移到 SSD／HDD

RAM
↓ ページアウト
SSD／HDD

## スワッピングとの違い

### スワッピング
- English：Swapping
- 中文：換出換入
- 通常以整個程式或プロセス為單位搬移

### ページング
- English：Paging
- 中文：分頁
- 將程式拆成固定大小的ページ，只搬移需要的部分

快速區別：

- スワッピング：整個程式搬動
- ページング：一頁一頁搬動

## スラッシング
- English：Thrashing
- 中文：顛簸現象／頻繁換頁
- ページイン和ページアウト發生得過於頻繁
- 系統花大量時間搬動ページ，而不是執行真正的程式
- 會造成系統效能大幅下降

## 快速記憶
- ページ：虛擬記憶體中的小區塊
- ページフレーム：RAM 中放置ページ的區塊
- 需要的ページ不在 RAM → ページフォールト
- SSD／HDD → RAM → ページイン
- RAM → SSD／HDD → ページアウト
- 換頁過於頻繁 → スラッシング
