# データのバックアップ

> [!summary] 一句話
> フル備份全部資料；差分保存自上次完整備份後的變更；増分只保存自上次任何備份後的變更。

## フルバックアップ
中文：**完整備份**

- 每次都備份全部資料
- 備份時間最長
- 需要容量最大
- 還原最簡單、最快

```text
每次＝全部備份
```

## 差分バックアップ
中文：**差異備份**

- 備份「上一次完整備份之後」所有變更的資料
- 越到後面，備份量越大
- 還原時需要：

```text
最新完整備份
＋
最新一次差異備份
```

## 増分バックアップ
中文：**增量備份**

- 每次只備份「上一次備份之後」的變更
- 備份時間最短
- 需要容量最小
- 還原較麻煩
- 還原時需要：

```text
最新完整備份
＋
之後所有增量備份
```

## 比較
|**類型**|**備份內容**|**備份速度**|**還原**|
|---|---|---|---|
|完整備份|全部資料|最慢|最簡單|
|差異備份|完整備份後的全部變更|中等|中等|
|增量備份|上一次備份後的變更|最快|最麻煩|

## FE考點
```text
フル＝每次全部

差分＝和完整備份比

増分＝和上一次備份比
```
