# 標準化

> [!summary] 一句話
> デジュール標準由正式標準機構制定；デファクト標準因市場普及形成；フォーラム標準由企業聯盟制定。

## 標準形成方式

| 種類 | 形成方式 | 特徵 |
|---|---|---|
| デジュールスタンダード | 正式標準機構制定 | 公開程序與共識 |
| デファクトスタンダード | 市場競爭後廣泛普及 | 事實上的標準 |
| フォーラムスタンダード | 特定企業或團體共同制定 | 速度較快、業界導向 |

## 主要標準化組織

| 組織 | 主要領域 |
|---|---|
| ISO | 一般國際標準 |
| IEC | 電氣與電子技術 |
| ITU | 電信與無線通訊 |
| IEEE | 電氣、電子、電腦與網路技術 |
| JIS | 日本産業規格 |
| IETF | Internet技術標準，發布RFC |
| W3C | Web技術標準 |

## 常見標準

- ISO 9001：品質管理系統
- ISO/IEC 27001：資訊安全管理系統
- ISO 14001：環境管理系統
- IEEE 802.3：Ethernet
- IEEE 802.11：無線LAN

## 標準化的目的

- 確保互換性與接続性
- 提升品質與安全
- 降低成本
- 促進市場普及
- 避免特定廠商的封閉規格造成障礙

## FE考點

- 正式機構制定：デジュール
- 市場占有形成：デファクト
- 企業聯盟制定：フォーラム
- 國際一般標準：ISO
- 電氣電子：IEC／IEEE
- Internet的RFC：IETF

## 易錯點

- RFC並不全部都是正式標準，需看其status
- IEEE不是日本國內標準機構
- JIS的I已改稱「産業」，不是舊稱「工業」

## 快速記憶

> 法定、事實、聯盟，分別對應de jure、de facto、forum。
