# 減価償却の基本

> [!summary] 一句話
> 取得價額不是一次全部列為費用，而是在耐用年数內按期分配為減価償却費。

## 核心概念

設備等固定資産會跨多期使用，因此把成本分配到受益期間。

| 用語 | 意義 |
|---|---|
| 取得価額 | 購入並投入使用所需的總成本 |
| 耐用年数 | 預計使用年數 |
| 残存価額 | 使用結束後預計剩餘價值 |
| 減価償却費 | 當期列入的費用 |
| 減価償却累計額 | 歷年折舊費累計 |
| 帳簿価額 | 取得価額−累計折舊 |

## 不進行減価償却的典型資産

- 土地：通常不因使用而有明確耐用年數
- 建設仮勘定：尚未投入使用
- 棚卸資産：屬流動資産，使用売上原価處理

## 現金與費用的差別

設備購入時可能一次支付現金，但費用分多年認列。

因此：

- 購入年度的現金支出可能很大
- 每年的減価償却費只是一部分
- 減価償却費本身通常不伴隨當期現金流出

## 帳簿価額

期末帳簿価額＝取得価額−減価償却累計額

例：取得價額500萬円，累計折舊200萬円：

帳簿価額＝300萬円

## FE考點

- 折舊目的：費用與收益的期間對應
- 題目問未折舊餘額：帳簿価額
- 土地通常不折舊
- 折舊費是費用，但不一定是當期現金支出

## 易錯點

- 帳簿価額不等於市場價格
- 耐用年数不一定等於實際可使用年數
- 折舊不代表企業另外存了一筆現金

## 快速記憶

> 現金可能一次付，費用要分年算。
