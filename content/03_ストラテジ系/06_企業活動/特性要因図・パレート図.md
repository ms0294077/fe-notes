# 特性要因図・パレート図

> [!summary] 一句話
> 特性要因図整理原因；パレート図按影響大小排列以找出重要少數。

## OR・IEで用いる分析手法
## 特性要因図
- **用語：** 特性要因図（とくせいよういんず）／特性要因圖、因果圖
也稱：

- 魚骨図（ぎょこつず）
- フィッシュボーン・ダイアグラム
- 石川ダイアグラム

將某個結果及其可能原因按照類別整理，找出問題的真正原因。

例如產品不良率過高時，可按照 **4M** 分析：

- Man：人員
- Machine：機器
- Material：材料
- Method：方法

```text
產品不良
├─ 人員：教育不足、操作失誤
├─ 機器：設備老化、保養不足
├─ 材料：品質不穩、保存不當
└─ 方法：流程不合理、檢查不足
```

### FE關鍵詞
```text
原因と結果
真の原因
原因を分類
魚骨図
→ 特性要因図
```

分析「為什麼發生問題」。

## パレート図
- **用語：** パレート図（Pareto Chart／柏拉圖）
由以下兩部分組成：

- 按數值由大到小排列的棒狀圖
- 顯示累積比率的折線圖

用途是找出影響最大的項目，決定改善工作的優先順序。

例如產品不良：

```text
刮傷：50件
尺寸錯誤：25件
顏色錯誤：15件
其他：10件
```

應優先改善件數最多的「刮傷」。

與 **80：20法則** 有關：

大部分問題，通常集中在少數主要原因上。

### FE關鍵詞
```text
大きい順
累積比率
改善の優先順位
重点項目
→ パレート図
```

分析「應該先改善哪個問題」。
