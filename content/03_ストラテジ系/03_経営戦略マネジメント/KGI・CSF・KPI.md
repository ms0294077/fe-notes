# KGI・CSF・KPI

> [!summary] 一句話
> KGI 定義最終目標，CSF 找出成功關鍵，KPI 用中間指標持續衡量進度。

## 核心概念

最終目標を達成するために、目標・成功条件・進捗指標を整理する方法。

```text
KGI
＝最終的に何を達成するか

CSF
＝成功するために何が重要か

KPI
＝途中経過をどの数値で確認するか
```

## KGI
- **用語：** Key Goal Indicator／重要目標達成指標
最終的に達成したい成果を数値で示したもの。

例：

- 年間売上高を20％増加
- 利益を1億円にする
- 市場占有率を15％にする
- 顧客離脱率を5％以下にする

最後の結果を見る指標。

## CSF
- **用語：** Critical Success Factor／重要成功要因
KGIを達成するために必要な重要要素。

例：

- 新規顧客を増やす
- リピート率を高める
- 来店者数を増やす
- 平均購入金額を高める

CSFは通常、数値そのものではなく、重点的に取り組む方向を表す。

成功のために何をするべきか。

## KPI
- **用語：** Key Performance Indicator／重要業績評価指標
CSFの進捗状況を確認するための具体的な数値目標。

例：

- 毎月の新規顧客数500人
- リピート率40％
- 1日当たりの来店者数300人
- 平均購入金額8,000円

途中の進捗を確認する数値。

## 具体例
### KGI
```text
年間売上高を20％増加させる
```

### CSF
```text
新規顧客を増やす
リピート率を高める
平均購入金額を高める
```

### KPI
```text
毎月の新規顧客数500人
リピート率40％
平均購入金額8,000円
```

## 関係
```text
KPIを達成する
↓
CSFが実現する
↓
KGIを達成する
```

## 快速記憶
```text
最終目標
→ KGI

成功のための重要要素
→ CSF

進捗を測る数値
→ KPI
```

KGI看終點，CSF看成功條件，KPI看途中數字。
